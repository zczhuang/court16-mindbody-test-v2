The four decision points

1
Did the parent receive one valid Mindbody email?If no, staff helps. Do not send the explicit ConsumerWelcomeEmail; our test made a duplicate with a broken link.
2
Has the parent created the password and completed verification?The native email flow has no published API claim flag, so staff verifies this in Mindbody. OAuth can automate this state only if its consumer identity resolves to the exact stored parent Client ID. HubSpot never supplies the password link.
3
Has the parent added the child under Family?If no, ask the parent to sign in at Mindbody Account → Family → Add Member, using the child's exact name.
4
Is the existing child actually linked?Staff clicks Connect Mindbody Account once; parent uses Mindbody's link email and selects the child already listed. Complete only when staff sees Manage Family Account.
